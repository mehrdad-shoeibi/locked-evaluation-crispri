## 0. What A13 is, and what it is not

A13 records corrections to **reporting** of analyses that were already specified, already
executed, and already persisted. It is a housekeeping and disclosure instrument.

**A13 is not** a prospective scientific lock, not a new pre-registration, not a new
scientific amendment in the sense of choosing an analysis after seeing outcomes, and not
authorization for any further held-out evaluation.

**A13 changes no** hypothesis, endpoint, split, control, seed, metric, held-out access
rule, model, estimator choice, scientific decision rule, or primary result. It computes
nothing. Every number it cites is transcribed from an already-persisted artifact.

## 1. A3 §2 — the RPE1 population reconciliation

### 1.1 What A3 specified

A3 fixed two matched cell counts mechanically, with no discretionary choice
(`experiment_specs/lock_amendment_A3.md:55-64`):

> "**Two `n` values, both mechanically derived from cell counts alone. No arbitrary
> choice.** … `n_match = 27` — `max(min_VCC, min_RPE1, min_K562) = max(10, 25, 27)`,
> derived mechanically from the three observed minima. **All K562-essential constructs
> qualify. VCC constructs with < 27 cells are dropped, and so are RPE1 constructs with
> 25–26 cells.**"

The minima entering that derivation came from A3's own table
(`lock_amendment_A3.md:18-22`), whose RPE1 row is `median 73 | IQR 48–113 | min 25 |
max 3,451 | n 1,932`.

### 1.2 What the executed sensitivity actually operated on

The executed A3 §2 sensitivity used the **construction-matched persisted-embedding cell
set**, so that `x_cell` and `z` share one cell set per A3 §2.1
(`experiment_specs/matched_sensitivity_and_vcc_diagnostic.md:48-54`):

> "**Construction-matched cell set (important).** For each construct the analysis uses the
> cells that have a persisted embedding — so `x_cell` and `z` share one cell set (A3 §2.1).
> … For RPE1 the embedding set ([FEATURE-PIPELINE] phasec) carries ~5% more cells per construct than the
> revision H5 `x_cell` accumulator set (a separate QC filter) … Disclosed rather than
> hidden."

On that set RPE1's minimum is 27, not 25
(`matched_sensitivity_and_vcc_diagnostic.md:63-66`):

> "Note: on the construction-matched **embedding** cell set, RPE1's minimum is 27 (not the
> checkpoint-`x_cell` minimum of 25 that L11.2/A3 §2 anticipated), so RPE1 retains fully at
> n=27; the drop A3 flagged for RPE1's 25–26-cell constructs does not occur on this cell
> set. **Stated as a number, not inferred.**"

### 1.3 The consequence, stated plainly

    THRESHOLD_DERIVATION_OBJECT = CHECKPOINT x_cell / revision cell-count accumulator
                                  (RPE1 min 25, median 73, IQR [48,113], NT pool 11,007)
    EXECUTION_OBJECT            = CONSTRUCTION-MATCHED PERSISTED-EMBEDDING CELL SET
                                  (RPE1 min 27, median 76, IQR [50,118], NT pool 11,485)
    THRESHOLD_DERIVATION_OBJECT != EXECUTION_OBJECT

The `25` that entered `max(10, 25, 27)` was measured on a different object from the one
the resulting threshold was applied to. The threshold itself is unchanged and is **not**
retrospectively revised; only the reporting of its derivation and of the resulting
retention is corrected.

### 1.4 Persisted retention at `n_match = 27`

Transcribed from `matched_sensitivity_and_vcc_diagnostic.md:58-61` and `:186`:

| screen | total | retained | dropped |
|---|---|---|---|
| VCC | 5,740 | 2,843 | 2,897 |
| RPE1 | 1,932 | **1,932** | **0** |
| K562-essential | 1,903 | 1,903 | 0 |

At `n_match = 10` all three screens retain in full (5,740 / 1,932 / 1,903).

### 1.5 The two RPE1 summaries are two populations, not two estimates

    76 [50,118]  -> embedding cell set        (the set A3 §2 executed on)
    73 [48,113]  -> checkpoint x_cell set     (the set A3's minima table came from)

Both cover the **same 1,932 constructs** and differ only in which cells per construct are
included, because a separate QC filter applies to the accumulator set. They are therefore
not inconsistent measurements of one population. `experiment_specs/phase4_prep.md:528`
records both and declines to adjudicate:

> `RPE1_CELLSET_DISCREPANCY: EMBEDDING set ([FEATURE-PIPELINE] phasec) min=27 median=76 NT=11485 ->
> z_rpe1_1932 + L12 matched artifacts ; CHECKPOINT x_cell set (revision accumulator)
> min=25 median=73 NT=11007 -> persisted x_cell_rpe1_1932_mapped + L11.2 medians. Both
> recorded; neither declared correct.`

`matched_sensitivity_and_vcc_diagnostic.md:77-78` states the same relation directly:
"RPE1's full median here is 76 on the embedding cell set vs L11.2's 73 on the checkpoint
set — same cell-set difference noted above."

### 1.6 What A13 repairs

The mismatch was recorded at execution time, in L12, before any A3 result was reported.
It was not discovered later and it is not a defect in the executed analysis. What was
defective is the **manuscript's communication of it**: the final text did not make the
two populations distinguishable, and the reader could take the executed RPE1 minimum to be
25. A13 repairs reporting only. No retention count was recomputed for this amendment.

## 2. A1 and A2 — discharge of two pre-specified reporting obligations

### 2.1 Both secondaries were pre-specified

A1 (`experiment_specs/lock_amendment_A1.md:88-91`):

> "- **SECONDARY: `x_release`** — as submitted, unchanged. Reported alongside, in full, in
> the appendix.
>
> Both are reported for every external arm they enter. **Neither is dropped.**"

and `lock_amendment_A1.md:128-129`: "the primary external analysis therefore uses the
construction-matched `x_cell`, with `x_release` reported in full as a secondary analysis."

A2 (`experiment_specs/lock_amendment_A2.md:49-50`):

> "For every external arm containing `m̃`, a **linear head** is added as a **secondary**
> analysis, reported alongside the frozen primary. It replaces nothing."

with the implementation fixed at `lock_amendment_A2.md:65-66` as ordinary
`sklearn.linear_model.LinearRegression` with `fit_intercept=True` and otherwise default.

### 2.2 Both were executed, and their results persist

`iclr2027_revision/phase4/phase4_secondary.json`, key `note`:

> `"SECONDARIES (A1§2 x_release, A2§2.1 linear, A4§3.1 MAX-LINEAR, A4§3.2 MAG+COUNT). None
> promoted."`

Execution ordering is consistent with A3's binding sequence
(`lock_amendment_A3.md:189`: "4. Pre-registered secondaries (A1's `x_release`, A2's linear
head)"): `phase4_results.md:12-13` records the primary persisted `2026-08-13T06:15:35Z`
with "Secondaries and Part C run only after."

### 2.3 A display asset existed and was never placed

`iclr2027_revision/w1_assets/tables/table_fm_secondary.tex` carries the header
`% W1 asset (Part D3). Provenance: iclr2027_revision/phase4/phase4_secondary.json.` Its
values were verified cell-by-cell against that JSON on 2026-08-29 and agree exactly; no
value in either representation was altered.

`iclr2027_revision/W2cA_start_state.md:37` records the state:

> "**W1 assets NOT yet placed** (`iclr2027_revision/w1_assets/`): … tables table_fm_vcc,
> table_fm_external_primary, table_fm_secondary, table_cellcount_confound,
> table_cellcount_by_screen."

**Non-placement is not an authorized decision to drop.** A repository-wide search found no
positive record documenting a decision to omit either secondary. A1 forbids dropping
`x_release`; A2 requires the linear secondary alongside the frozen primary. The obligations
were therefore outstanding, and A13 records their discharge in the manuscript appendix.

### 2.4 Scope limits that travel with the restored reporting

A2 §2.2 (`lock_amendment_A2.md:83`) restricts the linear secondary to arms **containing
`m̃`**, not `z`-only arms. Accordingly the restored reporting:

- does **not** re-evaluate H-FM3;
- does **not** alter the z-only external results (RPE1 −0.139, K562-essential −0.267);
- does **not** replace or compete with the frozen primary;
- authorizes **no** post-outcome model or head selection.

It establishes head- and feature-basis sensitivity of the magnitude-augmented arm, which
is exactly the contingency A2 anticipated when it required both to be reported.

### 2.5 A cell-set metadata field that must not be over-read

`phase4/phase4_secondary.json` contains:

    RPE1_cellset_for_counts = "CHECKPOINT (min 25) — the set that produced x_cell/m̃"

This is **count-population metadata recorded in the secondary result artifact**. It
describes the cell population behind the count-derived quantities in that artifact. It is
**not** a qualifier on the Spearman estimates, and it must not be written or implied that
the reported `rho` values were computed on a restricted 25-cell population. It is also a
different population from the construction-matched embedding set used by A3 §2 (§1 above);
the two must not be conflated, and L12's embedding-cell-set assumption must not be carried
into the secondary table.

## 3. Table 7 — an unsupported shared qualifier

The dataset-statistics table carried the row label `Label mean (std), train split` spanning
both columns, with values VCC `4.23 (0.81)` and K562-essential `3.99 (2.75)`.

- The qualifier is **correct for the VCC column**: `experiment_specs/phase1_vcc.md:200-201`
  records "VCC-train mean **4.227** — matches the manuscript's stated 4.23".
- The qualifier is **unsupported for the K562-essential column**: that column has no train
  split. The table's own row states `--- (held-out test only)` for Train/Val/Test rows.
- The exact population behind `3.99 (2.75)` is **NOT DETERMINABLE** from the governed
  Project-B record. Its cited provenance is `PHASE10A`
  (`paper_v2/VERIFICATION_REPORT.md:336`), and no `PHASE10A` document exists anywhere in
  this repository. `iclr2027_revision/R8_REPORT.md:88-89` independently classifies these
  figures as "Descriptive dataset statistics with no governed artifact … label ranges
  [0,5.72]/[0,8.71], std 0.81/2.75".
- The qualifier is a **later editorial addition**, not a change of statistic. The identical
  numeric pair appears in nine copies of this table; six earlier copies label the row
  simply `Label mean (std)`. The qualifier is present only in the v7 baseline and the two
  trees derived from it.

**Correction:** the shared qualifier is removed, restoring `Label mean (std)`. Neither
numeric value is changed, and **no replacement K562 split qualifier is invented**, because
none is supported by the record.

## 5. Chronology and unblinding wording

The locked protocol required external outcomes to be held out until final evaluation. That
requirement is unchanged and is not weakened here.

Separately, what the **surviving local record** establishes is narrower than an absolute
historical claim: it positively locates the first documented external-outcome access at
final evaluation, and it does not exclude undocumented earlier access. Manuscript wording
is aligned to the epistemic bound already present in the chronology appendix, so that the
protocol requirement and the forensic finding are stated as the distinct things they are.

Historical amendment records use "committed" in their contemporaneous local-record sense.
Git history shows that A1–A4 first entered version control later. Claims about their
pre-result timing therefore rest on the surviving contemporaneous local records and
artifact chronology, not on a pre-unblinding Git commit. This is clarified in the derived
release documentation rather than by rewriting the historical records.
