## 0. Scope

A16 repairs exactly two defects and nothing else:

1. **Broken release-level references to a non-shipped evidence file.** The derived supplement
   README cites an internal evidence record four times, but that file is deliberately not included in the
   anonymous release package. The references are therefore unresolvable for a reader of the
   release.
2. **One chronology sentence whose wording exceeds the surviving evidence bound.** The H-FM2
   outcome paragraph states that the direction of the result "was fixed in advance of seeing it",
   which asserts as historical fact something the record does not establish.

A16 states explicitly that:

- **no scientific result changes**;
- **no numerical value changes**;
- **no experiment is added**;
- **no analysis is rerun**;
- **no model, head, metric, control, seed, split, endpoint or estimator changes**;
- **no held-out outcome is accessed**;
- **no figure changes**.

It performs no computation of any kind.

## 1. Defect 1 — references to a non-shipped internal evidence record

The cited record is an internal evidence file held in the working repository. It is **not**
shipped in the anonymous supplement, and it is not added by this amendment: internal evidence
records may carry identifiers, machine-local paths, and material deliberately excluded from an
anonymous release. The correct repair is to make the release self-contained, not to widen it.

Each of the four references is redirected to an artifact that is actually shipped and that
actually supports the same statement, or, where no shipped artifact supports it, the sentence is
narrowed to what the release package itself establishes:

| README site | claim being supported | resolution |
|---|---|---|
| A5 scope / chronology (list entry) | A5's scope and its filelessness | already carried by the shipped `02_amendments/A6.md` header and by the README's own A5 section; the redundant pointer is dropped |
| A5 scope (A5 section) | same | retained pointer to the shipped `02_amendments/A6.md` header; the `R5` half is dropped |
| A6 parenthetical | that an *earlier internal evidence pass* recorded A6 as not yet existing | **no shipped artifact supports this**; the parenthetical is removed rather than redirected. A6's own committed date, already stated in the same bullet, is what the release supports |
| held-out access-count limit | that a single unqualified all-in access count is not derivable | redirected to the shipped `02_amendments/A9.md` §4 ("What is NOT established" / "The defensible statement") and to the manuscript's held-out data access ledger |

No provenance is invented. No shipped amendment is described as proving something it does not
state. Canonical historical evidence records are not modified.

After repair the release must contain no reference to that record, and every local filename
the README cites must resolve inside the shipped supplement.

## 2. Defect 2 — the H-FM2 chronology sentence

The H-FM2 outcome paragraph closes with:

> "The direction of this result was fixed in advance of seeing it."

The governing evidence standard, unchanged since A13 and restated in A9 §4, is:

> **The surviving local record positively locates the first documented external-outcome access at
> final evaluation while not excluding undocumented earlier access.**

"In advance of seeing it" asserts that the result had not been seen earlier, which is stronger
than the record supports. The sentence is rescoped to the documented record:

> "The expected direction was recorded before the first documented external-outcome access."

This is a wording change only. Every adjacent H-FM2 quantity, interval, interpretation, table
reference and verdict is untouched, including the reported $\rho = -0.139$ on RPE1 and $-0.267$ on
K562-essential and the statement that the gate passed and the pre-registered expectation was met.

The separate, legitimate use of "fixed in advance" describing the five controls is a statement
about specification content rather than about what had been seen, and is not part of this defect.

internal label, Figure 2's panel wording, Figure 5's label, legacy appendix wording, prose style,
