# Lock Amendment A10 — Phase-B numerical baseline

**PROSPECTIVELY LOCKED BY AUTHOR DECISION — 2026-08-29**
**POST-UNBLINDING NUMERICAL-REPRODUCIBILITY RULE**
**NO SCIENTIFIC RESULT OBSERVED UNDER THIS BASELINE YET**

## Scope and non-scope

This amendment governs **future Phase-B execution only**. It:

- changes **no** historical result;
- changes **no** historical gate verdict;
- changes **no** scientific hypothesis, endpoint, split, control, seed, or metric;
- introduces **no** tolerance of any kind;
- is fixed **before** any new Phase-B scientific result exists.

The historical Phase-0 scaler exact-regeneration gate returned **MISMATCH** and **remains
MISMATCH**. Nothing here reinterprets, relaxes, supersedes or retroactively passes it. The durable
forensic record is `provenance/PHASEB_SCALER_FORENSIC_FINDING_2026-08-29.md`.

The gate A10 establishes is a **different, prospective** gate. It asks: *can the exact scaler state
that future Phase-B runs will consume be regenerated exactly from the committed environment
artifact, the frozen canonical inputs and the numerical policy below?* That question is answerable
going forward; the historical one was not.

Part 1 is not retroactively characterized as violating any rule here. It re-fit its scalers in
process (`pipeline/run_phase1_select.py:24-26`) under a governance regime that contained no
load-only rule, because none existed.

## §1 — Process-start thread policy

Every Phase-B scientific process **must** be launched with

    OMP_NUM_THREADS=1  OPENBLAS_NUM_THREADS=1  MKL_NUM_THREADS=1
    VECLIB_MAXIMUM_THREADS=1  NUMEXPR_NUM_THREADS=1

set **before** interpreter startup. Setting them inside a running interpreter does not reconfigure
an already-initialized BLAS threadpool and is not compliant.

Basis: with bit-identical operands, thread count alone was shown to alter the float32 `x @ R`
product by more than the historical mismatch (forensic finding, item 6).

## §2 — Runtime verification

Before any scientific computation the process must call `threadpoolctl.threadpool_info()` and
verify every controllable pool reports one thread. On violation: **hard abort before computation**.
Record `THREAD_POLICY_REQUESTED`, `THREAD_POLICY_REALIZED`, `THREAD_POLICY_CHECK`.

## §3 — Numerical environment

The environment is pinned by a **materializable artifact**, not a prose version list:

    environment/phaseB/phaseB_requirements_locked.txt
    environment/phaseB/phaseB_environment_README.md

The BLAS is carried inside the NumPy wheel, so pinning NumPy pins the BLAS build. The interpreter
version is part of the specification and must be verified at runtime. The artifact has been rebuilt
from and verified against the canonical scaler state; see
`provenance/PHASEB_NUMERICAL_BASELINE_MANIFEST.json`.

## §4 — Fit once, load thereafter

Canonical Phase-B `z`, `C2` and `ceiling_x` scaler state is fit **once**, during the
reproducibility-reset baseline, on VCC **train** only, and is thereafter an **immutable input**.

State is persisted as version-independent NumPy arrays (`mean_`, `scale_`, `var_`,
`n_samples_seen_`) rather than pickled estimators, so reloading does not depend on the
scikit-learn version — directly addressing the failure mode the forensic record documents.

    provenance/phaseB_baseline/phaseB_z_scaler_state.npz
    provenance/phaseB_baseline/phaseB_c2_scaler_state.npz
    provenance/phaseB_baseline/phaseB_ceiling_x_scaler_state.npz

**No H-FM4, D-MECH, identification-ladder or other Phase-B scientific runner may call
`StandardScaler.fit()` for the governed canonical `z` / `C2` / `ceiling_x` inputs.** A runner may
only LOAD, VERIFY HASH, VERIFY STATE, and TRANSFORM. A refit attempt is a **hard abort**
(`pipeline/phaseB_preprocessing.py::refit_forbidden`).

## §5 — Scientific construction unchanged

A10 changes numerical **execution** only. The canonical row order, key scheme, dtype path, the C2
seed and frozen projection matrix, the feature definitions and the scaler scope are inherited
unchanged from the frozen record (`lock:167-171`, `lock:316-318`; `pipeline/m_tilde.py:38-47`;
`pipeline/phase1_harness.py:60,69`; `pipeline/fm_preprocess.py:15-16`; `pipeline/controls.py:37-49`).

## §6 — Gate

    PHASEB_REPRODUCIBILITY_GATE = PASS
      iff the canonical scaler state regenerates EXACTLY (mean_, scale_, var_ elementwise;
      n_samples_seen_ semantically) in (a) a fresh process in the same environment and
      (b) an independent environment rebuilt from the committed artifact.

No tolerance, no `allclose`, no rounding. On failure, Phase-B scientific execution is blocked.

## §7 — What this amendment does not establish

It does not determine the historical numerical cause, does not show that Part-1 reported results
consumed a mismatched persisted artifact (they did not load the pickles at all), and does not
license any scientific execution. Execution requires separate authorization.
