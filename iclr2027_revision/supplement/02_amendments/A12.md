# Lock Amendment A12 — D-TARGET-VAR target-structure diagnostic

**PROSPECTIVELY LOCKED BY AUTHOR DECISION — 2026-08-29 UTC**
**POST-D-MECH-RESULT · PRE-D-TARGET-VAR-RESULT**
**DESIGN DIAGNOSTIC — NOT A RESCUE ANALYSIS**

## 1. Chronology, stated plainly

> **D-TARGET-VAR was proposed after the locked D-MECH result had been observed and archived. Its
> specification and estimands were frozen before any D-TARGET-VAR result was observed.**

This amendment is **deliberately outside the scope of A11**. A11 governed the D-MECH probe, which is
**closed and consumed** (archived at `fb1ac7db01874a6c1e75201b48880feabc83049a`). A11's prohibition on
exploratory target summaries governed **D-MECH itself**; this diagnostic is a distinct, later exercise
with a distinct purpose — characterising the clustering / effective-unit structure of the target before
deciding whether any future nonlinear recoverability probe is worth designing.

It must **not** be described as: preregistered before D-MECH; part of A11; planned before D-MECH; or
designed blind to the D-MECH result. It was none of those.

**The result may inform future study design. It may not be used to retrospectively change, soften,
rescue, reinterpret or explain away the consumed D-MECH result.** No D-MECH-NL decision is made here.

## 2. The only question

How strongly is the already-defined target

```
t_i = numpy.log1p(n_perturbed_cells_i)      natural log, float64
```

clustered by **(A) target_gene** and **(B) batch**, within VCC TRAIN and VALIDATION **separately**?

It does **not** answer: whether `z` predicts `t`; whether Geneformer encodes sampling depth; whether
D-MECH should have been positive; why D-MECH was non-positive; why external transfer fails; whether
sampling depth or endpoint construction causes external failure; or whether D-MECH-NL should be run.

## 3. Target and rows — inherited unchanged from the consumed D-MECH authority

`n_perturbed_cells` keeps **exactly** the D-MECH definition: the count of **all** perturbed cells in the
`(target_gene, batch)` group, under the same retained-row eligibility. The count is **not** redefined,
subsampled, standardized, centred, normalized, winsorized, outlier-trimmed, or re-filtered.

```
ROW_KEY            = (split, batch, target_gene)

EXPECTED_VALIDATION_ROWS = 2052
```

TRAIN and VALIDATION are analysed **separately and never pooled**. If the real input does not reproduce
those row populations, the run **aborts before any D-TARGET-VAR result is computed**.

## 5. The four locked analysis cells

```
1. TRAIN      x target_gene        3. VALIDATION x target_gene
2. TRAIN      x batch              4. VALIDATION x batch
```

No pooled TRAIN+VALIDATION cell. Per cell: `N_ROWS`, `N_GROUPS`, and explicitly `N_GENES` (gene
grouping) or `N_BATCHES` (batch grouping); plus `GROUP_SIZE_MIN`, `GROUP_SIZE_MEDIAN`,
`GROUP_SIZE_MAX`, `GROUP_SIZE_MEAN`. **No additional exploratory quantiles.**

## 6. Frozen one-way variance-component estimator

With `N` rows, `k` groups, sizes `m_i`, values `t_ij`, grand mean `t̄`, group means `t̄_i`:

```
SSB      = Σ_i m_i (t̄_i − t̄)²
SSW      = Σ_i Σ_j (t_ij − t̄_i)²
TOTAL_SS = Σ_rows (t − t̄)²          check TOTAL_SS ≈ SSB + SSW; record SS_RESIDUAL
MSB      = SSB / (k − 1)
MSW      = SSW / (N − k)
m0       = (N − Σ_i m_i²/N) / (k − 1)          unbalanced-design correction
VAR_WITHIN  = MSW
VAR_BETWEEN = (MSB − MSW) / m0                 NOT clipped to zero
ICC         = VAR_BETWEEN / (VAR_BETWEEN + VAR_WITHIN)   NOT clipped to [0,1]
ETA_SQUARED = SSB / TOTAL_SS
```

**`ETA_SQUARED` is a descriptive raw sum-of-squares fraction. It is NOT interchangeable with `ICC`.** It
must not be used alone to infer the clustering-adjusted effective statistical unit, and unlike the
variance-component ICC it does **not** correct the between-group sum of squares for the expected
within-group contribution.

## 7. Two design-effect approximations — both required, neither preferred

Cluster sizes are unequal, so no single mean cluster size is chosen. Both are reported:

```
M_BAR_ARITHMETIC    = N / k
M_BAR_SIZE_WEIGHTED = Σ_i m_i² / N            mechanically ≥ M_BAR_ARITHMETIC,
                                              with equality only when sizes are equal

DESIGN_EFFECT_APPROX_ARITH    = 1 + (M_BAR_ARITHMETIC    − 1) · ICC
DESIGN_EFFECT_APPROX_WEIGHTED = 1 + (M_BAR_SIZE_WEIGHTED − 1) · ICC

ICC_DESIGN_EFFECT_APPROX_N_ARITH    = N / DESIGN_EFFECT_APPROX_ARITH
ICC_DESIGN_EFFECT_APPROX_N_WEIGHTED = N / DESIGN_EFFECT_APPROX_WEIGHTED
```

These names are used verbatim in the result artifacts and are **never collapsed into one
`EFFECTIVE_N`**.

**Both are conventional ICC/design-effect diagnostic approximations. Neither is an exact count of
independent observations. Neither is a formal power calculation. Neither is guaranteed to equal or
bracket the true amount of independent information available to a downstream prediction procedure.**
They do not jointly account for gene and batch dependence, model complexity, covariate structure, other
dependence structures, cross-group heterogeneity, or all consequences of unequal cluster sizes.

**Direction depends on the sign of ICC.** For **positive** ICC, `M_BAR_SIZE_WEIGHTED ≥ M_BAR_ARITHMETIC`
implies the weighted design effect is ≥ the arithmetic one and its approximate N is ≤ the arithmetic
one — so for positive ICC the weighted variant is the more conservative of the two with respect to
apparent independent information. **For negative ICC that ordering reverses.** Therefore it may **not**
be stated that the weighted variant is universally more conservative. Both are reported mechanically,
and neither is selected because it suits a later claim.

## 8. Negative ICC and invalid design effects

A negative method-of-moments ICC is **not clipped**. Both design effects are computed mechanically when
finite. A negative ICC may yield `DESIGN_EFFECT_APPROX < 1` and an approximate N greater than `N`; those
values are retained together with this statement:

> "This is a mechanical consequence of the negative method-of-moments ICC estimate and must not be
> interpreted literally as more independent observations than observed rows."

**Per variant independently:** if its `DESIGN_EFFECT_APPROX ≤ 0` or is non-finite, the corresponding
`ICC_DESIGN_EFFECT_APPROX_N_*` is set to `NOT_INTERPRETABLE`. The formula is never replaced post hoc.

## 9. The two axes are NOT a joint decomposition

The `target_gene` and `batch` analyses are **two separate one-way decompositions**. No two-way model is
authorized.

`ICC_target_gene` and `ICC_batch` are therefore each one-way estimates computed independently. They are
**mutually confounded to an unquantified degree**. They **must not be added**, **must not be subtracted
to assign variance**, and **must not be read as percentages of one common decomposed total**. A larger
ICC on one axis does **not** establish that the variance "belongs" to that axis rather than the other.
Resolving gene-versus-batch attribution would require a different design — an appropriate joint or
multilevel decomposition — which this lock deliberately does not authorize.

## 10. Small-k batch caveat

Every batch result reports `N_BATCHES` beside its ICC, with this stated immediately alongside:

> "The batch ICC is estimated from N_BATCHES = k groups; when k is small, the between-batch mean square
> and resulting method-of-moments between-group component may be unstable."

No numerical threshold for "small" is assigned, the caveat is not turned into a hypothesis test, and it
is not used to discard the batch result.

## 11. No decision thresholds

No definition is created for high/low ICC, strong/weak clustering, near or substantially above
`N_GENES`, adequate or inadequate effective N, or enough/insufficient power. **No threshold is created
for whether D-MECH-NL should be run.** The result is archived first; a later, explicitly post-diagnostic
design decision may take these values as input, and that decision is not part of this lock.

## 12. Interpretation ceiling

**Allowed:** report `ICC_target_gene`, `ICC_batch`, both design-effect approximations, and per grouping
`N_ROWS`, both approximate Ns, and the ratios `N_ROWS / approximate N` — **with no adjective for the
magnitude of those ratios**, and reporting `NOT_INTERPRETABLE` for the ratio whenever its approximate N
is `NOT_INTERPRETABLE`. TRAIN and VALIDATION may be compared descriptively by their reported numbers.
The results may be said to characterise target clustering and to possibly inform future design.

**Mandatory qualification, wherever the values are reported:**

> "ICC_target_gene and ICC_batch are separate one-way estimates, are mutually confounded to an
> unquantified degree, and do not constitute a joint variance decomposition."

**Not allowed:** reinterpreting or explaining away D-MECH; stating D-MECH was underpowered or had
adequate power; calling either approximate N the true effective sample size; concluding that row-level
analysis is invalid or that gene-level or batch-level analysis is definitively correct; claiming RF/HGB
would or would not solve the problem; claiming Geneformer does or does not encode sampling depth;
claiming sampling depth or endpoint mismatch explains external transfer.

## 13. Implementation, guards and execution

CPU-only runner at `iclr2027_revision/pipeline/run_d_target_var.py`. It may load only `split`, `batch`,
`target_gene`, `n_perturbed_cells`. TRAIN and VALIDATION only; **TEST and unknown splits are explicitly
rejected**. Prohibited: model imports, sklearn estimator imports, `z` loads, external-data loads,
network access, GPU use, random sampling, bootstrap, CI, p-value, hypothesis test, correlation, mixed
model, two-way ANOVA, nested model, plots, and any extra target summary. No randomness is required.

**Two-commit pre-result freeze.** Commit 1 is this specification. Commit 2 is the finished runner plus
synthetic-test evidence and the pre-run implementation record. **No real ICC, eta-squared, variance
component, group-size summary, design effect, approximate N, or N/approximate-N ratio may be observed
before Commit 2**; observing one sets `PRE_RESULT_FREEZE_VIOLATION = YES` and stops the task.

Synthetic tests only before freeze, covering at minimum: balanced groups; unequal sizes; zero
between-group difference; a negative `VAR_BETWEEN`/ICC case; `SSB + SSW ≈ TOTAL_SS`; ICC not clipped;
`M_BAR_SIZE_WEIGHTED ≥ M_BAR_ARITHMETIC`; equality of the two mean cluster sizes for balanced groups;
the positive-ICC ordering of the two design effects; the negative-ICC reversal; design effect ≤ 0
handling; `NOT_INTERPRETABLE` behaviour; ratio outputs; and absence of prohibited imports. Synthetic
values are never derived from the real target, and no real statistic is printed during testing.

**Pre-run guards** (all must pass, else abort): HEAD equals the implementation commit; target source
hash matches; target realpath inside Project B; runner hash equals the committed runner;
`Z_ACCESS = NO`, `MODEL_IMPORT = NO`, `VCC_TEST_ACCESS = NO`, `EXTERNAL_ACCESS = NO`,
`PROJECT_A_SCIENCE_ACCESS = NO`, `GPU_USE = NO`; and the governed population identity
TRAIN = 5740 / VALIDATION = 2052 verified **without computing the locked decomposition before freeze**.

**Exactly one real execution**, CPU-only, into a new immutable UTC-stamped external run directory that
is never overwritten.

## 14. Structural validation

Exactly four cells; TRAIN `N_ROWS` = 5740 and VALIDATION `N_ROWS` = 2052 in both grouping views. Per
cell: `k > 1`, `N > k`, `m0 > 0`, `TOTAL_SS` finite and `> 0`, `SSB`/`SSW`/`MSB`/`MSW` finite, the
`SSB + SSW` consistency check PASS, ICC persisted unclipped, `ETA_SQUARED` persisted, both `M_BAR`
variants persisted, and both design effects and both approximate Ns following the frozen formulas and
guard rules. Any failed invariant marks the result **INVALID**. **Formulas are never changed after
seeing the result.**
